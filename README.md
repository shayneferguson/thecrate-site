The Crate — Institute for Creative Thought

A responsive record-label placeholder for https://thecrate.ca, hosted on GitHub Pages. Typography is real HTML; the worn paper and spindle are a separate background image.

The opening plays once per page load over 9.55 seconds: wordmark, catalogue details, institute lines, headline, introduction and footer. Motion waits for the paper and fonts. Reduced-motion visitors get the complete stationary label. Without JavaScript, the original static HTML remains readable. A bounded startup fallback prevents hidden text when resources fail.

Motion timing is in motion.js; easing and masks are in motion.css. The original text and positions remain in index.html. The separate soundtrack control starts Out the Crate (74 BPM, 3:29). The first ten seconds of typography follow the audio clock, including pause/resume; the complete label then holds while the track continues. No autoplay or looping. The 320 kbps MP3 is the approved full song, with separated vocals arranged over Throop Avenue Last Call in SoundCraft. The original instrumental and all editable audio sources are preserved. Audio loads only when requested. Native audio controls remain available without JavaScript.

Editable FigCraft and DesignCraft documents, motion source copies and the source builder are kept in the studio project, outside the public repository.
